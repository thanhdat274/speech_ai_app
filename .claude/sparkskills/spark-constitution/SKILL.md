# Spark Constitution

## Purpose
Create a Project Constitution - guidelines and principles that guide all development decisions.

## When to Use
- Starting a new project
- Establishing team standards
- Refactoring to improve quality

## Process

1. **Analyze project context** - understand goals and constraints
2. **Elicit requirements** - ask about quality, architecture, performance needs
3. **Generate constitution** - create CONSTITUTION.md with tailored principles
4. **Validate** - review with user and adjust

## Output
Creates `CONSTITUTION.md` with:
- Core principles
- Code quality standards
- Architecture guidelines
- Performance requirements
- Security standards
- Documentation requirements

## Integration
Works with other SparkSkills: brainstorm → constitution → specify → plan → implement
