# Spark Brainstorm

## Purpose
Refine rough ideas through Socratic questioning and explore alternatives.

## When to Use
- Early in project (before constitution)
- When requirements are unclear
- Before committing to a design

## Process

1. **Listen to rough idea** - Understand what user wants
2. **Ask clarifying questions** - Explore the "why"
3. **Present alternatives** - Show different approaches
4. **Document design** - Save decisions made

## Output
Saves design discussion to `DESIGN.md`

## Usage Example
```
/spark.brainstorm I want a photo organizing app
```

**Claude asks:**
- What problem are you solving?
- Who is the target audience?
- What are the key features?
- Any constraints I should know?
