# spark debug

Systematic 4-phase root cause analysis.

## Usage

```
/spark.debug
```

## Process

1. **Observation** - What's happening vs expected?
2. **Isolation** - Narrow down scope
3. **Root Cause** - Why did this happen?
4. **Fix & Prevent** - Fix and prevent regression

## When to Use

- Code doesn't work
- Bugs appear unexpectedly
- Debugging taking too long

## Output

Debug report with:
- Problem description
- Root cause
- Fix applied
- Prevention measures
