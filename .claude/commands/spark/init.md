# spark init

Initialize a new project with SparkSkill setup.

## Usage

```
/spark.init <PROJECT_NAME>
```

## What it does

1. Creates project structure
2. Sets up CONSTITUTION.md
3. Initializes git worktree
4. Prepares for spark.specify

## Example

```
/spark.init my-photo-app
```

Creates a new project with SparkSkill ready to go.
