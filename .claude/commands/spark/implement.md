# spark implement

Execute tasks with TDD cycle.

## Usage

```
/spark.implement
```

## Process

For each task:
1. Write failing test (RED)
2. Write minimal code (GREEN)
3. Refactor (REFACTOR)

Repeats until all tasks complete.

## Guardrails

**Always:**
- Tests first
- Small commits
- Update TASKS.md

**Never:**
- Code without test
- Skip refactoring
